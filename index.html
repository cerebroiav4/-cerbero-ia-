Como conectar o TradingView

  1. Adicione o indicador cerebro_meta_tradingview.pine ao gráfico.
  2. Configure o token no indicador igual ao WEBHOOK_SECRET do servidor.
  3. Crie um alerta usando Any alert() function call.
  4. Use a URL https://SEU-SERVICO.onrender.com/webhook/tradingview.

Este painel registra alertas técnicos. Não executa ordens na corretora, não fornece cotações próprias e não contém ainda calendário econômico/COT/seasonality. Sinais não garantem resultado.
